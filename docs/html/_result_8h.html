LDL_LIBRARY void LDL_ResultAddMessage ( LDL_Result * result,
const char * format,
... )

Adds a formatted error message to the result object.

This function appends a formatted message to the result object's internal message buffer. When a message is added, the result state is automatically set to a failure state.

Parameters
resultPointer to the result object.
formatA printf-style format string followed by additional arguments.
...Variable arguments to be formatted according to the format string.
Note
This function uses variable arguments (variadic) similar to printf.
The message is appended to any existing messages, allowing for accumulation of multiple error diagnostics.
After calling this function, LDL_ResultIsFail will return true.
The format string must be compatible with the standard printf formatting specifiers.
// Example usage:
LDL_Result* result = LDL_ResultCreate();
LDL_ResultAddMessage(result, "Failed to open file: %s", filename);
LDL_ResultAddMessage(result, "Error code: %d", errno);

LDL_LIBRARY LDL_Result * LDL_ResultCreate ( )

Creates a new result object.

This function allocates and initializes a new LDL_Result object in a default state (success with no messages). The object can be used to track the success or failure of operations throughout the library.

Returns
A pointer to the newly created LDL_Result instance, or NULL on allocation failure.
Note
The returned result object must be freed using LDL_ResultDestroy when it is no longer needed to avoid memory leaks.
Initially, the result object is in a success state with no messages.

LDL_LIBRARY const char * LDL_ResultGetMessage ( LDL_Result * result)

Retrieves the current error message from the result object.

This function returns a pointer to a string containing the accumulated error messages from the result object. The message provides diagnostic information about why an operation failed.

Parameters
resultPointer to the result object.
Returns
A pointer to a constant string containing the error message, or NULL if no message is available.
Note
The returned string is owned by the result object and should not be modified or freed by the caller.
The message may contain multiple lines or formatted diagnostic information depending on what was added.
If the result is in a success state, this may return NULL or a generic success message.

LDL_LIBRARY void LDL_ResultReset ( LDL_Result * result)

Resets the result object to its initial state.

This function clears all stored messages and resets the result state back to success. This allows the same result object to be reused for multiple operations without allocating a new one.

Parameters
resultPointer to the result object to reset.
Note
After reset, LDL_ResultIsOk will return true and LDL_ResultGetMessage will return NULL or an empty string.
This function is useful for reusing a result object across multiple operations in a loop or sequential processing.
Any previously stored messages are freed and no longer accessible.
// Example: Reuse result object
LDL_Result* result = LDL_ResultCreate();
for (int i = 0; i < 10; i++) {
LDL_ResultReset(result);
// Perform operation with result tracking...
if (LDL_ResultIsFail(result)) {
printf("Operation %d failed: %s\n", i, LDL_ResultGetMessage(result));
}
}
