LDL_LIBRARY LDL_BmpLoader * LDL_BmpLoaderCreate ( LDL_Result * result)

Creates a new BMP loader instance.

This function allocates and initializes a new LDL_BmpLoader object. The instance can be used to load BMP files and retrieve their pixel data.

Parameters
resultPointer to an LDL_Result variable that will receive the operation status. If the operation succeeds, the result will be set to success state. If an error occurs, the result will contain an appropriate error message.
Returns
A pointer to the newly created LDL_BmpLoader instance, or NULL on failure.
Note
The returned BMP loader must be freed using LDL_BmpLoaderDestroy when it is no longer needed to avoid memory leaks.

LDL_LIBRARY uint8_t LDL_BmpLoaderGetBytesPerPixels ( LDL_BmpLoader * loader)

Retrieves the number of bytes per pixel for the loaded BMP image.

This function returns the memory footprint of a single pixel based on the loaded BMP image's pixel format.

Parameters
loaderPointer to the BMP loader instance.
Returns
The number of bytes per pixel (e.g., 3 for RGB24, 4 for RGBA32). Returns 0 if no image is loaded.
Note
This value is derived from the pixel format of the loaded BMP.
Common BMP formats:
  • 24-bit BMP: 3 bytes per pixel (RGB)
  • 32-bit BMP: 4 bytes per pixel (RGBA)

◆ LDL_BmpLoaderGetPixels()

LDL_LIBRARY uint8_t * LDL_BmpLoaderGetPixels ( LDL_BmpLoader * loader)

Retrieves a pointer to the loaded BMP pixel data.

This function returns a pointer to the raw pixel data of the currently loaded BMP image. The data format can be determined using the LDL_BmpLoaderGetPixelFormat function.

Parameters
loaderPointer to the BMP loader instance.
Returns
A pointer to uint8_t buffer containing the image pixel data. Returns NULL if no image is loaded or if an error occurs.
Note
The pixel data is owned by the BMP loader and should not be freed by the caller. The data remains valid as long as the loader exists and no new image is loaded.
The buffer size can be calculated as: width * height * LDL_BmpLoaderGetBytesPerPixels(loader)
The data is stored in row-major order, typically with bottom-to-top row order (BMP format standard).

LDL_LIBRARY LDL_Vec2i LDL_BmpLoaderGetSize ( LDL_BmpLoader * loader)

Retrieves the dimensions of the loaded BMP image.

This function returns the width and height of the currently loaded BMP image in pixels.

Parameters
loaderPointer to the BMP loader instance.
Returns
The dimensions of the loaded image as an LDL_Vec2i structure. If no image is loaded, returns a vector with both components set to 0.
Note
The dimensions are extracted from the BMP file header.
The width and height are always positive for valid BMP files.

LDL_LIBRARY bool LDL_BmpLoaderLoadFromFile ( LDL_BmpLoader * loader,
const char * path )

Loads a BMP image from a file.

This function loads and parses a BMP image from the specified file path into the BMP loader. The image data can then be accessed using other functions such as LDL_BmpLoaderGetPixels and LDL_BmpLoaderGetSize.

Parameters
loaderPointer to the BMP loader instance.
pathPath to the BMP file to load. The path can be absolute or relative.
Returns
true if the BMP file was successfully loaded, false otherwise.
Note
Supported BMP formats include:
  • 24-bit uncompressed RGB
  • 32-bit uncompressed RGBA
  • Various compression methods (RLE, etc.)
If a previous image was loaded, it will be replaced by the new one.
The function validates the BMP header and ensures the file is a valid BMP.
Error details can be retrieved from the result object passed to LDL_BmpLoaderCreate if the loader was created with one.
