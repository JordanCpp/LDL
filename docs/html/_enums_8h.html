Keyboard Key Codes

Enumeration of all supported keyboard keys.

These values represent physical keys on a standard keyboard. They are used to identify which key was pressed or released in keyboard events.

The values are organized into logical groups:

  • System keys (Windows/Command, Menu)
  • Symbol keys (;, /, =, -, [, ], etc.)
  • Navigation keys (Arrow keys, Page Up/Down, Home, End, etc.)
  • Function keys (F1-F15)
  • Number pad keys (Numpad 0-9)
  • Alphanumeric keys (A-Z, 0-9)
  • Modifier keys (Shift, Control)

enum LDL_ContextType

Defines the type of rendering context used by the application.

This enumeration specifies the rendering backend or API that the application will use for drawing operations.

Enumerator
LDL_ContextSoftware 

Software-based rendering - CPU rendered.

Software-based rendering - uses CPU for all rendering operations.

LDL_ContextOpenGLLegacy 

Legacy OpenGL rendering context - fixed-function pipeline.

Legacy OpenGL rendering context - supports fixed-function pipeline (OpenGL 1.x-2.x).

LDL_ContextOpenGLHybrid 

Hybrid OpenGL rendering context - mixed legacy/modern.

Hybrid OpenGL rendering context - combines legacy and modern features.

LDL_ContextOpenGLModern 

Modern OpenGL (Core Profile) rendering context - shader-based.

Modern OpenGL rendering context - uses core profile (OpenGL 3.x+).

LDL_ContextMax 

Sentinel value representing the total number of contexts.

Sentinel value representing the total number of context types.

Note
The context type affects which rendering functions are available.
Some context types may not be supported on all platforms.
