LDL_LIBRARY LDL_Texture * LDL_TextureCreateFromPixels ( LDL_Result * result,
LDL_Context * context,
uint8_t pixelFormat,
LDL_Vec2i size,
uint8_t * pixels )

Creates a texture from pixel data.

This function allocates a new texture in GPU memory and initializes it with the provided pixel data. The texture is created with the specified dimensions and pixel format, and is associated with the given rendering context.

Parameters
resultPointer to an LDL_Result variable that will receive the operation status. If the operation succeeds, the result will be set to success state. If an error occurs, the result will contain an appropriate error message.
contextPointer to the rendering context that will own this texture.
pixelFormatThe pixel format of the texture (from LDL_PixelFormat enumeration).
sizeThe dimensions of the texture in pixels.
pixelsPointer to the pixel data buffer. Must be large enough to hold size.x * size.y * bytes_per_pixel bytes.
Returns
A pointer to the newly created LDL_Texture instance, or NULL on failure.
Note
The texture copies the pixel data into GPU memory; the original buffer can be freed after this call.
The context must be valid and initialized before creating textures.
The pixel format must be supported by the underlying graphics system.

Creates an empty texture of the specified size.

This function allocates a new texture in GPU memory with the specified dimensions and pixel format, but does not initialize the pixel data. The texture content is undefined until filled with data.

Parameters
resultPointer to an LDL_Result variable that will receive the operation status. If the operation succeeds, the result will be set to success state. If an error occurs, the result will contain an appropriate error message.
contextPointer to the rendering context that will own this texture.
pixelFormatThe pixel format of the texture (from LDL_PixelFormat enumeration).
sizeThe dimensions of the texture in pixels.
Returns
A pointer to the newly created LDL_Texture instance, or NULL on failure.
Note
This function is useful for creating render targets or textures that will be filled later.
The texture memory is allocated in GPU memory but not initialized.
The context must be valid and initialized before creating textures.

LDL_LIBRARY LDL_Texture * LDL_TextureCreateFromSurface ( LDL_Result * result,
LDL_Context * context,
LDL_Surface * surface )

Creates a texture from a surface.

This function creates a new texture in GPU memory by copying the pixel data from an existing LDL_Surface. The texture inherits the pixel format and dimensions of the surface.

Parameters
resultPointer to an LDL_Result variable that will receive the operation status. If the operation succeeds, the result will be set to success state. If an error occurs, the result will contain an appropriate error message.
contextPointer to the rendering context that will own this texture.
surfacePointer to the source surface containing the pixel data.
Returns
A pointer to the newly created LDL_Texture instance, or NULL on failure.
Note
The surface data is copied to GPU memory; the surface remains unchanged and can be destroyed separately.
This is the recommended way to convert surfaces to textures for accelerated rendering.
The surface's pixel format must be supported by the texture system.
Color key information from the surface is preserved.

◆ LDL_TextureDestroy()

LDL_LIBRARY void LDL_TextureDestroy ( LDL_Texture * texture)

Destroys a texture and frees all associated GPU resources.

This function releases all GPU memory and resources associated with the specified texture. After destruction, the texture pointer becomes invalid and should not be used.

Parameters
texturePointer to the texture to destroy.
Note
It is safe to pass NULL to this function; it will simply do nothing.
GPU memory is automatically released when the texture is destroyed.
All references to this texture in rendering operations become invalid.
