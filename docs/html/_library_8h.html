LDL_LIBRARY void LDL_LibraryClose ( LDL_Library * library)

Closes an open dynamic library.

This function unloads the currently opened dynamic library and releases all associated resources. After closing, function pointers obtained from this library become invalid and should not be used.

Parameters
libraryPointer to the library manager instance.
Note
This function has no effect if no library is currently open.
It is safe to call this function multiple times; subsequent calls will have no effect.

◆ LDL_LibraryCreate()

LDL_LIBRARY LDL_Library * LDL_LibraryCreate ( LDL_Result * result)

Creates a new library manager instance.

This function allocates and initializes a new LDL_Library object. The instance can be used to open dynamic libraries and retrieve function pointers from them.

Parameters
resultPointer to an LDL_Result variable that will receive the operation status. If the operation succeeds, the result will be set to LDL_RESULT_SUCCESS. If an error occurs, the result will contain an appropriate error code.
Returns
A pointer to the newly created LDL_Library instance, or NULL on failure.
Note
The returned library manager must be freed using LDL_LibraryDestroy when it is no longer needed to avoid memory leaks.

LDL_LIBRARY void LDL_LibraryDestroy ( LDL_Library * library)

Destroys a library manager instance and frees all associated resources.

This function releases all memory and resources associated with the specified library manager. If a library is currently open, it will be automatically closed before destruction.

Parameters
libraryPointer to the library manager instance to destroy.
Note
It is safe to pass NULL to this function; it will simply do nothing.

LDL_LIBRARY LDL_VoidFuncPtr LDL_LibraryGetFunction ( LDL_Library * library,
const char * name )

Retrieves a function pointer from the loaded library.

This function looks up a function symbol by name in the currently loaded dynamic library and returns a pointer to it. The returned pointer can be cast to the appropriate function type for calling.

Parameters
libraryPointer to the library manager instance.
nameThe name of the function to retrieve.
Returns
A function pointer to the requested symbol, or NULL if the symbol cannot be found or no library is currently open.
Note
The returned pointer should be cast to the appropriate function signature before being called.
Function name matching may be case-sensitive depending on the platform and compiler used to build the library.
This function may return NULL if the symbol is not exported or if name mangling is used.
Warning
Function pointers become invalid after the library is closed or destroyed.

◆ LDL_LibraryOpen()

LDL_LIBRARY bool LDL_LibraryOpen ( LDL_Library * library,
const char * path )

Opens a dynamic library from the specified file path.

This function loads a dynamic library from the given file path and makes its symbols available for function retrieval. The library remains loaded until explicitly closed or the library manager is destroyed.

Parameters
libraryPointer to the library manager instance.
pathPath to the dynamic library file to open.
  • On Windows: Typically a .dll file
  • On Linux/Unix: Typically a .so file
  • On macOS: Typically a .dylib or .bundle file
Returns
true if the library was successfully opened, false otherwise.
Note
If a library is already open, it will be automatically closed before opening the new one.
The path can be absolute or relative. On some platforms, the system library search path may also be used.
Use LDL_LibraryGetFunction to retrieve function pointers from the opened library.
