LDL_LIBRARY bool LDL_EventIsKeyPressed ( LDL_Event * event,
uint8_t key )

Checks if a specific keyboard key is currently in a pressed state within the provided event.

This function validates that the event is a keyboard event and that the specified key is in the pressed state.

Parameters
eventA pointer to the LDL_Event structure that contains the event data to be inspected.
keyThe identifier of the keyboard key to check (from LDL_Key enumeration).
Returns
A boolean value that is true if the specified key is in a pressed state; otherwise, false.
Note
The event must be of type LDL_EventIsKeyboard for this function to return true.
