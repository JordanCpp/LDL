◆ LDL_SurfaceCreateFromCapacity()

LDL_LIBRARY LDL_Surface * LDL_SurfaceCreateFromCapacity ( LDL_Result * result,
uint8_t pixelFormat,
LDL_Vec2i capacity )

Creates a surface with a specified capacity.

This function allocates a new surface with a buffer large enough to hold the specified capacity of pixels. The surface size is initially set to match the capacity, but can be modified later. Memory is allocated for the pixel data based on the pixel format.

Parameters
resultPointer to an LDL_Result variable that will receive the operation status. If the operation succeeds, the result will be set to success state. If an error occurs, the result will contain an appropriate error message.
pixelFormatThe pixel format to use for the surface (from LDL_PixelFormat enumeration).
capacityThe maximum number of pixels in each dimension.
Returns
A pointer to the newly created LDL_Surface instance, or NULL on failure.
Note
The capacity determines the maximum dimensions the surface can hold.
The actual size can be smaller than the capacity.
Memory is allocated as: capacity.x * capacity.y * bytes_per_pixel.

uint8_t pixelFormat,
LDL_Vec2i size,
uint8_t * pixels )

Creates a surface from existing pixel data.

This function creates a new surface that uses the provided pixel data without copying it. The surface takes ownership of the pixel data and will free it when destroyed.

Parameters
resultPointer to an LDL_Result variable that will receive the operation status. If the operation succeeds, the result will be set to success state. If an error occurs, the result will contain an appropriate error message.
pixelFormatThe pixel format of the provided data (from LDL_PixelFormat enumeration).
sizeThe dimensions of the pixel data in pixels.
pixelsPointer to the pixel data buffer. Must be large enough to hold size.x * size.y * bytes_per_pixel bytes.
Returns
A pointer to the newly created LDL_Surface instance, or NULL on failure.
Note
The surface takes ownership of the pixel data and will free it.
Do not free or modify the pixel data after passing it to this function.
The buffer must be properly aligned for the pixel format.

Creates a surface with a specified size.

This function allocates a new surface with dimensions exactly matching the specified size. Memory is allocated for the pixel data based on the pixel format and dimensions.

sizeThe dimensions of the surface in pixels.
Returns
A pointer to the newly created LDL_Surface instance, or NULL on failure.
Note

This is the most commonly used creation function for new surfaces.

This function returns the number of bytes in each row of the surface, which may be larger than the width * bytes_per_pixel due to alignment. The pitch is useful for performing efficient row-wise operations.
