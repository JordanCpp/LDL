LDL_LIBRARY bool LDL_FpsCounterCalc ( LDL_FpsCounter * fpsCounter)

Performs a calculation step to update the current Frames Per Second value.

This function processes the elapsed time since the last calculation or since the start of the timer to compute the updated frames per second metric. It increments the internal frame counter and calculates the FPS value at regular intervals.

Parameters
fpsCounterA pointer to the LDL_FpsCounter instance for which the calculation is being performed.
Returns
A boolean value that returns true if the calculation was successfully performed; otherwise, returns false.
Note
This function should be called once per frame, typically at the end of each frame rendering cycle.
The FPS value is updated at regular intervals (typically once per second) to provide stable readings.
The returned value indicates whether the FPS counter is ready to provide updated FPS data.

LDL_LIBRARY LDL_FpsCounter * LDL_FpsCounterCreate ( LDL_Result * result)

Creates and initializes a new instance of an LDL_FpsCounter.

This function allocates memory for a new FPS counter object and prepares its internal state for tracking frames per second. The outcome of the allocation and initialization process is recorded in the provided result pointer.

Parameters
resultA pointer to an LDL_Result structure that will receive the status code indicating whether the creation was successful or failed. If the operation succeeds, the result will be set to success state. If an error occurs, the result will contain an appropriate error message.
Returns
A pointer to the newly created LDL_FpsCounter instance if the operation succeeded; otherwise, a NULL pointer is returned.
Note
The returned FPS counter must be freed using LDL_FpsCounterDestroy when it is no longer needed to avoid memory leaks.
The counter is initialized with zero frames and a reset timer.

LDL_LIBRARY void LDL_FpsCounterDestroy ( LDL_FpsCounter * fpsCounter)

Destroys an existing FPS counter and releases all associated memory resources.

This function performs the necessary cleanup for the specified FPS counter instance, including the deallocation of any internal buffers or timing information used by the object. After this call, the pointer to the FPS counter becomes invalid.

Parameters
fpsCounterA pointer to the LDL_FpsCounter instance that is intended to be destroyed.
Note
It is safe to pass NULL to this function; it will simply do nothing.
All timing and frame count data is lost when the counter is destroyed.

LDL_LIBRARY size_t LDL_FpsCounterFps ( LDL_FpsCounter * fpsCounter)

Retrieves the most recently calculated Frames Per Second (FPS) value.

This function provides access to the numerical result of the latest calculation performed by the FPS counter instance. The value represents the number of frames rendered in the last second.

Parameters
fpsCounterA pointer to the LDL_FpsCounter instance from which the FPS value is being retrieved.
Returns
A value of type size_t representing the number of frames per second calculated for the current period.
Note
The returned value is only updated after calls to LDL_FpsCounterCalc.
If no calculation has been performed yet, the returned value will be 0.
The value is stable and represents the average FPS over the measurement period.
// Example: Display FPS in a window title
size_t fps = LDL_FpsCounterFps(fpsCounter);
char title[256];
snprintf(title, sizeof(title), "My Application - FPS: %zu", fps);
SetWindowTitle(title);

LDL_LIBRARY void LDL_FpsCounterStart ( LDL_FpsCounter * fpsCounter)

Starts or resets the internal timer of the FPS counter.

This function marks the beginning of a new measurement period by resetting the internal timestamp and frame counter. It is typically called at the start of a frame or before starting the main application loop.

Parameters
fpsCounterA pointer to the LDL_FpsCounter instance whose timer is being started or reset.
Note
After calling this function, the FPS counter will begin counting frames from zero.
This function should be called before the first frame or when resetting the measurement period is desired.
The timer uses the system's high-resolution timer for accurate measurements.
