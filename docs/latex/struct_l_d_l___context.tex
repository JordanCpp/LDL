\doxysubsection{Detailed Description}
Opaque structure representing a rendering context instance. 

This structure encapsulates all state and resources required for rendering operations. The context manages the rendering pipeline, including the drawing surface, rendering API state, and graphics resources.

Key responsibilities:\+
\begin{DoxyItemize}
\item Manages rendering state (Open\+GL context or software renderer)
\item Handles drawing operations
\item Owns textures and other GPU resources
\item Coordinates with window system for presentation
\end{DoxyItemize}
