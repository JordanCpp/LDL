Loads a BMP image from a file. 

This function loads and parses a BMP image from the specified file path into the BMP loader. The image data can then be accessed using other functions such as LDL\+\_\+\+Bmp\+Loader\+Get\+Pixels and LDL\+\_\+\+Bmp\+Loader\+Get\+Size.


\begin{DoxyParams}{Parameters}
{\em loader} & Pointer to the BMP loader instance. \\
\hline
{\em path} & Path to the BMP file to load. The path can be absolute or relative. \\
\hline
\end{DoxyParams}
\begin{DoxyReturn}{Returns}
true if the BMP file was successfully loaded, false otherwise.
\end{DoxyReturn}
\begin{DoxyNote}{Note}
Supported BMP formats include:\+
\begin{DoxyItemize}
\item 24-\/bit uncompressed RGB
\item 32-\/bit uncompressed RGBA
\item Various compression methods (RLE, etc.) 
\end{DoxyItemize}

If a previous image was loaded, it will be replaced by the new one. 

The function validates the BMP header and ensures the file is a valid BMP. 

Error details can be retrieved from the result object passed to LDL\+\_\+\+Bmp\+Loader\+Create if the loader was created with one. 
\end{DoxyNote}
