\doxysubsection{Detailed Description}
Opaque structure representing a vertex buffer object. 

This structure encapsulates a vertex buffer that stores vertex data for 3D rendering. The buffer format is defined by FVF flags and can contain position, color, normal, and texture coordinate data.

Key features:\+
\begin{DoxyItemize}
\item Configurable vertex format via FVF flags
\item Dynamic data upload
\item GPU memory storage for optimal performance
