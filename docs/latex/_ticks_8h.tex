Pauses program execution for a specified number of milliseconds. 

This function suspends the current thread\textquotesingle{}s execution for approximately the specified number of milliseconds. It is useful for implementing timing loops, animations, and controlling execution speed.


\begin{DoxyParams}{Parameters}
{\em count} & The number of milliseconds to delay. Must be a non-\/negative value.\\
\hline
\end{DoxyParams}
\begin{DoxyNote}{Note}
The actual delay may be slightly longer than requested due to system scheduling granularity and overhead. 

On some platforms, the minimum delay resolution may be higher than 1 millisecond (typically around 15-\/16ms on Windows). 

Calling this function with a value of 0 will typically yield the current thread\textquotesingle{}s remaining time slice to the operating system. 

This function blocks the calling thread, so use with caution in performance-\/critical sections or real-\/time applications. 

Common use cases include:\+
\begin{DoxyItemize}
\item Creating frame rate limits (e.\+g., 60 FPS cap)
\item Animation timing control
\item Simple polling loops with reduced CPU usage
\item Simulating delays in game loops
\end{DoxyItemize}
\end{DoxyNote}
\begin{DoxyWarning}{Warning}
This function is not suitable for precise timing or real-\/time applications due to OS scheduling variations. 

Do not use this function in performance-\/critical loops that require precise timing.
\end{DoxyWarning}

Retrieves the current system uptime in milliseconds. 

This function returns the number of milliseconds that have elapsed since the system was started or since an arbitrary starting point (typically system boot time). The value is monotonically increasing and is suitable for measuring time intervals and performance timing.

\begin{DoxyReturn}{Returns}
The current time value in milliseconds as a size\+\_\+t integer.
\end{DoxyReturn}
\begin{DoxyNote}{Note}
The actual start point (epoch) depends on the platform:\+
\begin{DoxyItemize}
\item On Windows:\+ Typically returns the time since system start (Get\+Tick\+Count)
\item On Linux/\+\+Unix:\+ Typically returns the time since system boot
\item On mac\+OS:\+ Returns the time since system boot 
\end{DoxyItemize}

The value may wrap around after approximately 49.\+7 days on some platforms if using a 32-\/bit counter. For longer durations, consider using higher-\/precision timers. 

This function is useful for:\+
\begin{DoxyItemize}
\item Frame timing and delta time calculations
\item Animation timing and interpolation
\item Performance profiling and benchmarking
\item Timeout and interval management
\end{DoxyItemize}
\end{DoxyNote}
