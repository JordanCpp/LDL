\doxysubsection{Detailed Description}
Opaque structure representing a BMP image loader. 

This structure encapsulates the state and data required for loading and parsing BMP (Bitmap) image files. It provides functionality to load BMP files from disk, extract pixel data, and retrieve image properties such as dimensions and format.

Key features:\+
\begin{DoxyItemize}
\item BMP file loading and parsing
\item Support for various BMP formats (24-\/bit, 32-\/bit, etc.)
\item Pixel data extraction
\item Error handling through \doxylink{struct_l_d_l___result}{LDL\+\_\+\+Result} mechanism
\end{DoxyItemize}

\begin{DoxyNote}{Note}
The BMP loader handles both compressed and uncompressed BMP files. 

The loader manages its own memory for pixel data. 
\end{DoxyNote}
