Creates a texture from pixel data. 

This function allocates a new texture in GPU memory and initializes it with the provided pixel data. The texture is created with the specified dimensions and pixel format, and is associated with the given rendering context.

Creates a texture from a surface. 

This function creates a new texture in GPU memory by copying the pixel data from an existing \doxylink{struct_l_d_l___surface}{LDL\+\_\+\+Surface}. The texture inherits the pixel format and dimensions of the surface.


\begin{DoxyParams}{Parameters}
{\em result} & Pointer to an \doxylink{struct_l_d_l___result}{LDL\+\_\+\+Result} variable that will receive the operation status. If the operation succeeds, the result will be set to success state. If an error occurs, the result will contain an appropriate error message. \\
\hline
{\em context} & Pointer to the rendering context that will own this texture. \\
\hline
{\em surface} & Pointer to the source surface containing the pixel data. \\
\hline
\end{DoxyParams}
\begin{DoxyReturn}{Returns}
A pointer to the newly created \doxylink{struct_l_d_l___texture}{LDL\+\_\+\+Texture} instance, or NULL on failure.
\end{DoxyReturn}
\begin{DoxyNote}{Note}
The surface data is copied to GPU memory; the surface remains unchanged and can be destroyed separately. 

This is the recommended way to convert surfaces to textures for accelerated rendering. 

The surface\textquotesingle{}s pixel format must be supported by the texture system. 

Color key information from the surface is preserved. 
\end{DoxyNote}
