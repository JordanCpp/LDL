\doxysubsection{Detailed Description}
An opaque structure representing an instance of the FPS counter. 

This structure encapsulates the state and timing information required to calculate and track frames per second. It manages internal timestamps, frame counters, and the calculated FPS value.

Key features:\+
\begin{DoxyItemize}
\item Frame counting and timing
\item Automatic FPS calculation
\item Performance monitoring
\item Error handling through \doxylink{struct_l_d_l___result}{LDL\+\_\+\+Result}
\end{DoxyItemize}
