Creates a surface with a specified capacity. 

This function allocates a new surface with a buffer large enough to hold the specified capacity of pixels. The surface size is initially set to match the capacity, but can be modified later. Memory is allocated for the pixel data based on the pixel format.


\begin{DoxyParams}{Parameters}
{\em result} & Pointer to an \doxylink{struct_l_d_l___result}{LDL\+\_\+\+Result} variable that will receive the operation status. If the operation succeeds, the result will be set to success state. If an error occurs, the result will contain an appropriate error message. \\
\hline
{\em pixel\+Format} & The pixel format to use for the surface (from LDL\+\_\+\+Pixel\+Format enumeration). \\
\hline
{\em capacity} & The maximum number of pixels in each dimension. \\
\hline
\end{DoxyParams}
\begin{DoxyReturn}{Returns}
A pointer to the newly created \doxylink{struct_l_d_l___surface}{LDL\+\_\+\+Surface} instance, or NULL on failure.
\end{DoxyReturn}
\begin{DoxyNote}{Note}
The capacity determines the maximum dimensions the surface can hold. 

The actual size can be smaller than the capacity. 

Memory is allocated as:\+ capacity.\+x \texorpdfstring{$\ast$}{*} capacity.\+y \texorpdfstring{$\ast$}{*} bytes\+\_\+per\+\_\+pixel. 
\end{DoxyNote}

This function creates a new surface that uses the provided pixel data without copying it. The surface takes ownership of the pixel data and will free it when destroyed.
