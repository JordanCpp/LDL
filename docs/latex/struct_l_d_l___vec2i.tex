\doxysubsection{Detailed Description}
A structure representing a 2D integer vector. 

This structure is used to represent points, positions, dimensions, or direction vectors in a 2D space using signed integer coordinates. It is commonly used for window coordinates, pixel positions, and image dimensions.

The coordinates are stored as signed 32-\/bit integers, providing a range of approximately -\/2.\+1 billion to 2.\+1 billion, which is sufficient for most graphics and computational applications.
