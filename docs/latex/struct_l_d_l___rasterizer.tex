\doxysubsection{Detailed Description}
Opaque structure representing a text rasterizer instance. 

This structure encapsulates the state and resources required for rendering text from a True\+Type font. It generates pixel data for text strings that can be used as textures or surfaces.

Key features:\+
\begin{DoxyItemize}
\item Text rendering to pixel buffer
\item UTF-\/8 string support
\item Configurable text color
\item Pixel format management
\item Size retrieval of rendered text
\end{DoxyItemize}

\begin{DoxyNote}{Note}
The rasterizer converts text to a pixel buffer that can be used for rendering or texture creation.
