\doxysubsection{Detailed Description}
Opaque structure representing a color palette. 

This structure encapsulates an array of colors that can be used for indexed color operations. A palette maps indices to actual RGBA colors, allowing efficient color management and lookup.

Key features:\+
\begin{DoxyItemize}
\item Stores up to 256 colors (LDL\+\_\+\+Palette\+Max)
\item RGBA color support for each entry
\item Index-\/based color access
\item Memory-\/efficient color management
\end{DoxyItemize}

Common use cases:\+
\begin{DoxyItemize}
\item 8-\/bit image rendering
\item Palette-\/based animation
\item Color lookup tables (CLUTs)
\item Legacy graphics formats
\item Color quantization
\end{DoxyItemize}

\begin{DoxyNote}{Note}
The palette is initialized with default colors when created. 

Each color entry stores 8-\/bit RGBA components. 
\end{DoxyNote}
