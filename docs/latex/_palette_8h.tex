Maximum number of colors that can be stored in a palette. 

This constant defines the maximum capacity of a palette, which is 256 colors. This is a common size for indexed color palettes used in many graphics formats (e.\+g., 8-\/bit BMP, GIF, and other indexed image formats).

\begin{DoxyNote}{Note}
The valid index range for palette operations is 0 to (LDL\+\_\+\+Palette\+Max -\/ 1). 
\end{DoxyNote}

Creates and initializes a new palette instance. 

This function allocates memory for a new palette object and initializes it with default colors. The palette can hold up to LDL\+\_\+\+Palette\+Max colors (256 entries).

\begin{DoxyReturn}{Returns}
A pointer to the newly created \doxylink{struct_l_d_l___palette}{LDL\+\_\+\+Palette} instance if the allocation was successful; otherwise, a NULL pointer is returned.
\end{DoxyReturn}
\begin{DoxyNote}{Note}
The returned palette must be freed using LDL\+\_\+\+Palette\+Destroy when it is no longer needed to avoid memory leaks. 

The palette is initialized with default colors (typically black or a grayscale ramp) but can be customized using LDL\+\_\+\+Palette\+Set. 
\end{DoxyNote}
