Loads a True\+Type font from a file. 

This function loads a True\+Type font (.ttf) from the specified file path and prepares it for rendering at the specified size. The font is loaded into memory and can be used for text rasterization.


\begin{DoxyParams}{Parameters}
{\em result} & Pointer to an \doxylink{struct_l_d_l___result}{LDL\+\_\+\+Result} variable that will receive the operation status. If the operation succeeds, the result will be set to success state. If an error occurs, the result will contain an appropriate error message. \\
\hline
{\em path} & Path to the True\+Type font file (.ttf). The path can be absolute or relative. \\
\hline
{\em size} & The desired font size in points. This determines the height of the rendered text. \\
\hline
\end{DoxyParams}
\begin{DoxyReturn}{Returns}
A pointer to the newly created \doxylink{struct_l_d_l___font}{LDL\+\_\+\+Font} instance if the operation was successful; otherwise, a NULL pointer is returned.
\end{DoxyReturn}
\begin{DoxyNote}{Note}
The returned font must be freed using LDL\+\_\+\+Font\+Destroy when no longer needed. 

The font file must be a valid True\+Type font. 

The size parameter is in points (1/\+72 inch), typical values range from 12 to 72. 

Font loading may fail if the file does not exist or is not a valid TTF.
\end{DoxyNote}

This function renders the specified UTF-\/8 encoded text using the loaded font and color. The rendered text is stored in the rasterizer\textquotesingle{}s internal pixel buffer and can be retrieved using LDL\+\_\+\+Rasterizer\+Get\+Pixels.


\begin{DoxyParams}{Parameters}
{\em rasterizer} & A pointer to the \doxylink{struct_l_d_l___rasterizer}{LDL\+\_\+\+Rasterizer} instance. \\
\hline
{\em font} & A pointer to the \doxylink{struct_l_d_l___font}{LDL\+\_\+\+Font} to use for rendering. \\
\hline
{\em color} & The \doxylink{struct_l_d_l___color}{LDL\+\_\+\+Color} to use for text rendering (supports alpha). \\
\hline
{\em utf8\+\_\+text} & A null-\/terminated UTF-\/8 encoded string to render.\\
\hline
\end{DoxyParams}
\begin{DoxyNote}{Note}
The text is rendered with the specified color and font. 

The rasterizer\textquotesingle{}s internal buffer is resized to fit the text. 

Supports UTF-\/8 encoding for international characters. 

The rendered text includes alpha transparency for smooth edges. 

After rendering, use LDL\+\_\+\+Rasterizer\+Get\+Size and LDL\+\_\+\+Rasterizer\+Get\+Pixels to retrieve the result.
\end{DoxyNote}
