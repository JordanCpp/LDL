\doxysubsection{Detailed Description}
Opaque structure representing a 2D renderer instance. 

This structure encapsulates the state and resources required for 2D rendering operations. It manages drawing primitives, textures, layers, and color state for rendering to a window.

Key features:\+
\begin{DoxyItemize}
\item Drawing primitives (lines, filled rectangles)
\item Texture rendering with scaling and positioning
\item Layer management for depth ordering
\item Color state management
\item Batch rendering with Begin/\+\+End blocks
\end{DoxyItemize}
