Retrieves the current position of the mouse cursor. 

This function returns the current screen coordinates of the mouse cursor. The position is measured in pixels relative to the top-\/left corner of the screen or the active window, depending on the platform and context.

\item y:\+ Vertical coordinate (row) in pixels
\end{DoxyItemize}
\end{DoxyReturn}
\begin{DoxyNote}{Note}
The coordinate system origin (0, 0) is at the top-\/left corner. 

Positive x extends to the right, positive y extends downward. 

This function is useful for:\+
\begin{DoxyItemize}
\item Implementing custom cursor behavior
\item Tracking mouse input for UI interactions
\item Game development and camera control

Hides the mouse cursor. 

This function makes the mouse cursor invisible on the screen. The cursor remains functional but is not displayed. This is commonly used in applications that render custom cursors or want to provide an immersive experience (e.\+g., first-\/person games, full-\/screen applications).

\begin{DoxyNote}{Note}
The cursor is hidden globally or within the active window, depending on the platform. 

The cursor will typically reappear when:\+
\begin{DoxyItemize}
\item The application loses focus
\item The user moves the cursor outside the window
\item LDL\+\_\+\+Mouse\+Show is called
\item The application terminates 
\end{DoxyItemize}

Use cases:\+
\begin{DoxyItemize}
\item First-\/person shooter games with custom crosshairs
\item Full-\/screen multimedia applications
\item Immersive experiences
\item Screen recording or presentation software
\end{DoxyItemize}
\end{DoxyNote}
\begin{DoxyWarning}{Warning}
The cursor visibility state is application-\/specific and may not persist across application switches.
\end{DoxyWarning}
