Creates and initializes a new window instance. 

This function allocates memory for a new window object and initializes it with the specified parameters. The window is created with a rendering context and an associated screen surface.


\begin{DoxyParams}{Parameters}
{\em result} & Pointer to an \doxylink{struct_l_d_l___result}{LDL\+\_\+\+Result} variable that will receive the operation status. If the operation succeeds, the result will be set to success state. If an error occurs, the result will contain an appropriate error message. \\
\hline
{\em context} & Pointer to the rendering context that will be associated with this window. \\
\hline
{\em pos} & The initial position of the window (x, y coordinates) in screen space. \\
\hline
{\em size} & The initial dimensions of the window (width, height) in pixels. \\
\hline
{\em title} & The title string to display in the window title bar. \\
\hline
{\em mode} & Bitwise combination of window mode flags (from LDL\+\_\+\+Window\+Mode enumeration):\+
\begin{DoxyItemize}
\item LDL\+\_\+\+Window\+Mode\+Full\+Screen:\+ Fullscreen mode
\item LDL\+\_\+\+Window\+Mode\+Resized:\+ Allow resizing
\item LDL\+\_\+\+Window\+Mode\+Fixed:\+ Fixed size (non-\/resizable)
\item LDL\+\_\+\+Window\+Mode\+Centered:\+ Center window on screen
\item LDL\+\_\+\+Window\+Mode\+Minimized:\+ Start minimized
\item LDL\+\_\+\+Window\+Mode\+Maximized:\+ Start maximized 
\end{DoxyItemize}\\
\hline
\end{DoxyParams}
\begin{DoxyReturn}{Returns}
A pointer to the newly created \doxylink{struct_l_d_l___window}{LDL\+\_\+\+Window} instance if the operation was successful; otherwise, a NULL pointer is returned.
\end{DoxyReturn}
\begin{DoxyNote}{Note}
The returned window must be freed using LDL\+\_\+\+Window\+Destroy when no longer needed. 

The context must be valid and initialized before creating the window. 

If mode is 0, default window settings are used. 

The window\textquotesingle{}s screen surface can be accessed via LDL\+\_\+\+Window\+Get\+Screen.
\end{DoxyNote}

This function performs the necessary cleanup for the specified window, including the deallocation of the window handle, screen surface, and any associated resources. After this call, the pointer to the window becomes invalid.

It is safe to pass NULL to this function; it will simply do nothing.

The rendering context associated with the window should be destroyed separately after the window is destroyed.

This function polls the window\textquotesingle{}s event queue and returns the next pending event. If no events are available, the function returns false and the event structure is not modified.

Retrieves the screen surface of the window. 

This function returns a pointer to the window\textquotesingle{}s screen surface, which can be used for direct pixel manipulation and rendering. The surface represents the window\textquotesingle{}s drawing area.


\begin{DoxyParams}{Parameters}
{\em window} & A pointer to the \doxylink{struct_l_d_l___window}{LDL\+\_\+\+Window} instance. \\
\hline
\end{DoxyParams}
\begin{DoxyReturn}{Returns}
A pointer to the \doxylink{struct_l_d_l___surface}{LDL\+\_\+\+Surface} representing the window\textquotesingle{}s screen.
\end{DoxyReturn}
\begin{DoxyNote}{Note}
The surface is owned by the window and should not be destroyed separately. It will be automatically destroyed when the window is destroyed. 

Modifying the surface pixels allows custom rendering directly to the window. 

For software rendering, drawing directly to this surface is the primary method of rendering.
\end{DoxyNote}
