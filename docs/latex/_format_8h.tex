Formats a string using a variable number of arguments. 

This function processes a format string and substitutes placeholders with values passed directly as arguments to the function via an ellipsis (...). The resulting formatted string is stored within the specified formatter instance.


\begin{DoxyParams}{Parameters}
{\em formatter} & A pointer to the \doxylink{struct_l_d_l___formatter}{LDL\+\_\+\+Formatter} instance where the formatted result will be stored. \\
\hline

\hline
{\em ...} & A variable number of arguments that are to be formatted into the string according to the format specification. \\
\hline
\end{DoxyParams}
\begin{DoxyReturn}{Returns}
A pointer to the internal character buffer of the formatter containing the newly formatted string.
\end{DoxyReturn}
\begin{DoxyNote}{Note}
This is the primary formatting function for most use cases. 

The format string supports standard printf format specifiers:\+
\begin{DoxyItemize}
\item d, i:\+ signed integer
\item u:\+ unsigned integer
\item f:\+ floating point
\item s:\+ string
\item c:\+ character
\item x, X:\+ hexadecimal
\item p:\+ pointer 
\end{DoxyItemize}

The formatter\textquotesingle{}s previous content is replaced by the new format. 

This function is a wrapper around LDL\+\_\+\+Formatter\+VFormat.
\end{DoxyNote}

\hline
\end{DoxyParams}
