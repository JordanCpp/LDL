\doxysubsection{Detailed Description}
A unified structure that encapsulates all possible event types within a single object. 

This structure uses a type identifier to determine which member of the internal union is currently active and contains valid event data. This design allows for efficient event handling through a single event type while supporting multiple event variants.

Event types:\+
\begin{DoxyItemize}
\item LDL\+\_\+\+Event\+Is\+Quit:\+ Application quit request
\item LDL\+\_\+\+Event\+Is\+Mouse\+Move:\+ Mouse movement
\item LDL\+\_\+\+Event\+Is\+Mouse\+Click:\+ Mouse button click
\item LDL\+\_\+\+Event\+Is\+Resize:\+ Window resize
\item LDL\+\_\+\+Event\+Is\+Keyboard:\+ Keyboard input
\item LDL\+\_\+\+Event\+Is\+Gained\+Focus:\+ Window gained focus
\item LDL\+\_\+\+Event\+Is\+Lost\+Focus:\+ Window lost focus
\item LDL\+\_\+\+Event\+Is\+Mouse\+Scroll:\+ Mouse scroll wheel
\end{DoxyItemize}
