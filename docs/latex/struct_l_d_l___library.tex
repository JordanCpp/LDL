\doxysubsection{Detailed Description}
Opaque structure representing a dynamically loaded library. 

This structure encapsulates the handle and state of a loaded dynamic library. It is used as a handle for all library-\/related operations. The internal implementation details are hidden from the user to provide a platform-\/independent interface for dynamic library loading.
